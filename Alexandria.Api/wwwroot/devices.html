Pair New Device
Nickname

Copy the URL below and set it as the API endpoint on your Kobo:

  1. Connect your Kobo to your computer via USB.
  2. Open the file .kobo/Kobo/eReader.conf on the device.
  3. Find api_endpoint under [OneStoreServices].
  4. Replace the value with the URL above.
  5. Save the file, eject the device, and press Sync on your Kobo.
